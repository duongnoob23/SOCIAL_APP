# Bản đồ Tài liệu (Docs Navigation)

Chào mừng bạn đến với hệ thống tài liệu của dự án. 
Vui lòng sử dụng cấu trúc dưới đây để điều hướng:

- `/journal`: Nhật ký code hàng ngày.
- `/decisions`: Các quyết định kiến trúc và công nghệ (ADR).
- `/bugs`: Ghi chép lỗi và cách giải quyết.
- `/libraries`: Hướng dẫn sử dụng các thư viện trong dự án.
- `/patterns`: Các concept và design pattern áp dụng.
- `/setup`: Hướng dẫn thiết lập môi trường.
